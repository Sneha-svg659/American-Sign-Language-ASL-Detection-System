# American Sign Language (ASL) Detection System

## Overview
This project focuses on classifying American Sign Language hand gestures using deep learning and computer vision techniques.

## Objective
To recognize different ASL gestures from images using a Convolutional Neural Network (CNN).

## Technologies Used
- Python  
- TensorFlow / Keras  
- OpenCV  
- NumPy  

## Workflow
1. Image preprocessing (resizing, normalization)
2. Data augmentation to improve generalization
3. CNN model training
4. Model evaluation using accuracy metrics

## Results
The model learns meaningful visual features and achieves good classification performance on validation data.

- Increase dataset size
- Improve model architecture
